# Программа для вычисления корней квадратного уравнения calc_roots_program_from_file

Этот проект представляет собой программу с графическим интерфейсом, 
которая определяет корни квадратного уравнения и их количество.

## Аксиоматика:
1. ∀x If ∃ next symbol(ns) → ns = (+ || - || ^2)
2. ∀ комбинации коэффициента *a* и *x* ∃ в двух представления ax || a*x
3. После знака "/" ns ∉ {x, 0}
4. ∀ введенного выражения знак "=" встреяается единожды

>[!WARNING]
>_При нарушении аксиом за дальнейшее поведение программы отвечает пользователь
