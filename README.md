# Программа для вычисления корней квадратного уравнения calc_roots_program_from_file

Этот проект представляет собой программу с графическим интерфейсом, 
которая определяет корни квадратного уравнения и их количество.

## Режимы работы

>[!IMPORTANT]
>В левом верхнем углу окна программы находится кнопка **CHANGE_MODE** для смены режима программы, а так же индикатор текущего режима

1. **DEFAULT** - стандартный режим работы. Особенности:

- Ввод квадратного уровнения выполняется в окне программы в соответствии с аксиоматикой

- Выполнение рассчётов после нажатия кнопки **Solve**

- Отображение входных данных, их упрощённого вида и решения введённого уравнения

- Отображение части графика введённой функции в определённом диапазоне

2. **DYNAMIC** - динамический режим работы. Особенности:

- Ввод коэффициентов квадратного уровнения выполняется в окне программы с помощью слайдеров

- Выполнение рассчётов происходит после изменения любого из значений слайдеров

- Отображение квадратного уравнения и его решения

- Отображение части графика полученной функции в определённом диапазоне

## Аксиоматика:
1. ∀x If ∃ next symbol(ns) → ns = (+ || - || ^2)
2. ∀ комбинации коэффициента **a** и **x** ∃ в двух представления ax || a*x
3. После знака "**/**" ns ∉ {x, 0}
4. ∀ введенного выражения знак "**=**" встреяается единожды

>[!WARNING]
>_При нарушении аксиом за дальнейшее поведение программы отвечает пользователь_

## Библиотеки
>[!IMPORTANT]

## Компиляция

**Ввести в терминал один из пунктов**

- g++ -w -mwindows expr_solver.c tests.c base.c calc_roots.c input_output_mod.c calc_roots_program.c -o calc_roots_program

- start compile.bat

## Запуск

**Ввести в терминал**

- ./calc_roots_program

**Или вручную запустить**

- calc_roots_program.exe
